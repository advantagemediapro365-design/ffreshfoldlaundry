# Start Here - What the Developer Must Do First

This PDF is the first working checklist. The developer should begin by
creating the site structure and all required pages in Wix, then connect
the pages to the booking flow, service-area CMS, pricing content, and
lead capture forms.

> **Use this order:**

-   Create the main navigation pages and set clean URL slugs.

-   Create the service-area structure for Altoona, State College, Lock
    Haven, Blair County, and surrounding towns.

-   Create policy pages and make sure checkout links to them.

-   Add CTAs to every page: Book Pickup, Check My ZIP Code, Start
    Subscription, Join Delivery Pass, or Get Commercial Quote.

-   Add page-level SEO: SEO title, meta description, H1, H2 structure,
    internal links, and image alt text.

-   Build pages as drafts if unique content is not ready. Do not publish
    thin duplicate city pages.

-   Use Wix CMS/dynamic pages for service areas where possible instead
    of hard-coding every town page.

-   Keep all private addresses off public pages.

> **Assistant role: The assistant creates the SEO tracker, writes/enters
> content, renames images, adds alt text, checks mobile view, checks
> links, and flags broken pages for Tony/developer review.**

# SEO Rules For Every Page

-   One H1 per page only.

-   Every page needs an SEO title and meta description before
    publishing.

-   Every page must have a clean slug using lowercase words separated by
    hyphens.

-   Every public page must link to at least two other relevant pages.

-   Every service-area page must link to Pricing, Book Pickup,
    Subscriptions, Delivery Pass, Commercial Laundry, Service Areas, and
    Contact.

-   Every commercial page must link to Commercial Laundry, Pricing, Book
    Pickup, Service Areas, and Contact.

-   Every blog post must link to Book Pickup, Pricing, and Service
    Areas.

-   No private addresses on public pages.

-   No old pricing anywhere.

-   Do not keyword-stuff titles, headings, alt text, or copy.

-   Do not publish duplicate town pages without unique local text and
    FAQs.

> **Meta description formula:**
>
> Fresh Fold Delivery offers \[service\] in \[city/area\] with pickup,
> wash, dry, fold, delivery, subscriptions, and commercial options.
>
> **Example:**
>
> Fresh Fold Delivery offers laundry pickup and delivery in Altoona, PA
> with wash, dry, fold, subscriptions, add-ons, and commercial service.

# Developer Directions - Wix Structure

Build the site with a scalable service-area structure. Do not hard-code
every town manually if Wix CMS can manage service-area pages
dynamically.

> **Create a Service Areas CMS collection with these fields:**
>
> locationName \| slug \| county \| state \| zipCodes \| serviceStatus
> \| routeFrequency \| primaryKeyword \| secondaryKeywords \| seoTitle
> \| metaDescription \| h1 \| introCopy \| serviceCopy \| deliveryCopy
> \| subscriptionCopy \| commercialCopy \| localFAQ1 \| localFAQ2 \|
> localFAQ3 \| nearbyLocations \| primaryCTA \| secondaryCTA \|
> heroImage \| heroImageAlt \| publishedStatus \| noIndexStatus \|
> lastReviewed
>
> **Recommended service-area statuses:**

  -----------------------------------------------------------------------
  **Status**          **Meaning**
  ------------------- ---------------------------------------------------
  Active Daily        Daily or near-daily service is actively supported.

  Active Weekly       Weekly route service is actively supported.

  Route-Based         Service may be available on scheduled route days.

  Waitlist            Capture lead, do not promise service yet.

  Not Available       Show waitlist/custom quote option only.

  Custom Quote        Large, commercial, or distant service request needs
  Required            manual review.
  -----------------------------------------------------------------------

> **Create these basic Wix systems in Phase 1:**

-   Main marketing pages and service-area pages.

-   Booking form with service area, estimate, preferences, laundry photo
    upload, add-ons, delivery estimate, pickup reservation credit, and
    customer responsibility checkbox.

-   Commercial quote form.

-   Subscription interest/sign-up flow if payment setup supports it.

-   Delivery Pass page and sign-up flow if payment setup supports it.

-   Basic customer order confirmation flow.

-   Backend order records with status, actual weight, add-ons, delivery
    fee, tip, and notes.

-   Basic driver pickup/drop-off proof photo workflow.

-   Admin ability to view, edit, and assign orders.

# Local Service-Area Page Template

Every service-area page must be unique enough to deserve indexing. Use
this structure:

  -----------------------------------------------------------------------
  **Section**       **Required Content**
  ----------------- -----------------------------------------------------
  Hero              City-specific H1, short service promise, CTA buttons.

  Service status    Daily, weekly, route-based, waitlist, or custom quote
                    required.

  How it works      Book pickup, prepare laundry, driver pickup,
                    wash/dry/fold, delivery.

  Pricing preview   Point users to Pricing page and final rate card.

  Delivery          Base fee + round-trip mileage + route availability.
  explanation       

  Subscriptions     Student/household/family where relevant.

  Commercial option Businesses, Airbnb, salons, gyms, restaurants,
                    rentals.

  Local FAQ         At least 3 location-specific FAQs.

  Nearby areas      Link to nearby towns and main service-area page.

  Final CTA         Book Pickup or Check My ZIP Code.
